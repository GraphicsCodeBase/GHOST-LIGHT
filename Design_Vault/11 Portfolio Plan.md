# 11 · Portfolio Plan

## Every finished technique produces
1. **Write-up**: `Techniques/<Category>/<Name>/README.md` using [[Technique Writeup]]
2. **Before/after images** from the same camera bookmark
3. **Comparison vs reference**: error image + RMSE/FLIP
4. **Performance table**: GPU ms at 1080p, RTX 2070 Super
5. **30–60 s clip**: toggle the technique live **while interacting with the sandbox** (throwing objects, spawning lights). Dynamic scenes prove it works in a game context
6. **Limitations + what I'd do next**
