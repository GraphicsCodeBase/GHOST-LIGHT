# 09 · Assets

## Policy
- **Format:** glTF 2.0 for models, `.hdr` for environments. Others get converted by a script.
- **Location:** `Content/Assets/` (gitignored), except `Content/Assets/CREDITS.md` (committed).
- **Manifest:** `Content/AssetManifest.json` (committed) lists every asset: URL, **SHA-256**, size, license, attribution, and which scenes need it.
- `run.bat` downloads only what's missing, verifies checksums, and shows total size first.
- During dev sessions, **Claude asks before adding anything to the manifest or downloading it**.
- Large textures → BC7/BC5 at import (8 GB VRAM).

## Hosting decision (decided 2026-10-10)
| Asset type | How `run.bat` gets it |
|---|---|
| **Freely downloadable** (Khronos samples, Poly Haven, ambientCG, McGuire archive, Bitterli, blue noise) | Directly from the original source URL, pinned + checksummed |
| **License-gated** (NVIDIA ORCA Bistro / Zero Day, Intel New Sponza) | Checked **when the milestone needs it**. If the license allows redistribution → zip mirrored on **my GitHub Releases**, then fetched from there. If not → replaced with a free alternative scene |
| **Login-gated** (Mixamo) | Not used. Nothing may require a manual step |
| Procedural (Cornell box, test scenes) | Generated by the engine/scripts, no download |

Not using Git LFS: GitHub's free LFS quota is too small for scenes of this size.
